I# 🎮 Toddler Games

[Game Link](https://edenberga.github.io/kids-learning-game-/)

A collection of simple, colorful, toddler-friendly browser games designed for easy play on tablets and computers.

## 🌟 Games

### 🔤 Name Maze

A fun name-learning game where children can enter their name and fill the letters with colorful balls.

**Features:**

* Enter a child's name
* Large, colorful letters
* Simple tap/click interactions
* Designed for toddlers
* Works on tablets and computers

👉 [Play Name Maze](https://edenberga.github.io/kids-learning-game-/name-maze.html)

---

### 🚒 Fire Truck Maze

Help the fire truck find its way out of a randomly generated maze!

**Features:**

* New maze every time you restart
* Randomized paths
* Guaranteed solvable maze
* Use the keyboard arrow keys:

  * ⬆️ Up
  * ⬇️ Down
  * ⬅️ Left
  * ➡️ Right
* Celebration when the fire truck reaches the exit

👉 [Play Fire Truck Maze](https://edenberga.github.io/kids-learning-game-/fire-truck-maze.html)

## 🚀 Running the Games

These games are built with plain HTML, CSS, and JavaScript.

No installation or special software is required.

You can:

1. Download the repository.
2. Open `index.html` in a web browser.
3. Choose a game.
4. Start playing!
